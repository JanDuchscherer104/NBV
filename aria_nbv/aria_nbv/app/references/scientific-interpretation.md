# Scientific Interpretation Rubric

Use this only when a scientific plot or metric needs explanation beyond the
verdict-first sentence in the app guide.

State only fields that exist and materially change interpretation: definition,
units, assumptions, computational transform or formula, denominator or
normalization, intuition, and failure modes. Link exact notation, equation,
symbol, glossary, and implementation owners only when those canonical owners
exist. Never fabricate a formula, unit, or canonical link to complete the list.

Keep raw tables and exports subordinate and collapsed directly beneath the
interpretation. Operational counts and provenance remain on the lightweight
path in the parent guide.
