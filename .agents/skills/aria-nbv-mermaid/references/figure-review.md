# Figure critique: professor and student

Salvaged in scope from PR196: an explanatory brief, distinct review lenses and
artifact-based iteration. No thesis chapters, scientific renderer registry or
root governance are adopted from that stacked PR.

## Professor pass

Check the exact source revision. Does every arrow have the claimed information?
Trace one ordinary case, one boundary case and one counterexample. In Chapter 4:

- Physical feasibility cannot depend on target/horizon merely because the value
  branch does. Follow the physical branch before target-conditioned projection.
- A candidate-wise read is not a candidate-set interaction. Do not imply new
  dependencies through an attractive shared box.
- Pose-history updates are not newly acquired images or refreshed voxel fields.
  Causal selected GT depth is still privileged; causality does not make it sensed.
- Current-state dense rewards are not next-state one-step values. A backup must
  preserve successor support, termination and the selected estimator, including
  Double-Q selection/evaluation separation where applicable.
- Different histories mapping to the same state need not matter to this task.
  Harmful aliasing requires different relevant conditional decision laws.
- Strong decision-law equality is sufficient for Bellman closure; empirical
  ranking accuracy does not prove Markov sufficiency or identify a unique state.
- Proposed state carriers remain hypotheses. Alternatives are not additive
  modules, and candidate queries must not silently modify shared memory.

## Student pass

Read the rendered figure first, without its caption. Give its one-sentence
lesson; trace one datum from input to output; name the first unexplained symbol.
Identify current, privileged and proposed paths. If decoding requires reading
paragraphs inside boxes, simplify. If a dense equation dominates, put the full
derivation in text and show its named quantities and operations in the figure.

The caption then supplies definitions and the bounded interpretation. It should
answer a question left by the diagram, not repeat every label. The section must
introduce prerequisites before the figure and explain its consequence afterwards.

## Gate

Accept only if semantics, notation, actual-size legibility, clipping, grayscale,
caption entailment and unique explanatory value all pass. Syntax success alone
is not a gate. Same-context author self-checks must be named as such; genuine
independent review requires another reviewer seeing the exact artifact.
