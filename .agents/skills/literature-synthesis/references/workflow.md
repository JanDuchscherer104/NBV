# Screening and comparison workflow

1. State the answerable question and the bounded population, time range, or
   method family it covers.
2. Search the repository's current literature records first. Record why each
   candidate is included, excluded, or retained only as field orientation.
3. For selected work, inspect the primary source and record an exact locator,
   contribution, assumptions, evidence type, and limitation.
4. Build a small comparison matrix only across dimensions needed by the
   question. Keep incompatible tasks, settings, and evaluation protocols
   distinct instead of forcing a ranking.
5. Return the source packet and unresolved gaps to `academic-writing`; update
   the canonical literature or bibliography owner only when the task authorizes
   that repository change.

This local workflow selectively adapts source-screening and comparison mechanics
from [WenyuChiou/academic-writing-skills at
`cb56a7d`](https://github.com/WenyuChiou/academic-writing-skills/tree/cb56a7d0175f532a6c628c9829e1df824fa938d7).
The linked upstream skill is reference-only.
