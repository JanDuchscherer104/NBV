# Literature Synthesis

Prepare a bounded, source-traceable literature packet. This skill does not
write thesis arguments, edit bibliography files, or certify scientific claims.

## Workflow

1. Read `docs/AGENTS.md`, then the current
   [`sources.jsonl`](../../../docs/literature/sources.jsonl),
   [`references.bib`](../../../docs/references.bib), and the smallest matching
   literature review under [`docs/contents/literature/`](../../../docs/contents/literature/).
2. Read [`workflow.md`](references/workflow.md) and define the question,
   inclusion boundary, and comparison dimensions before collecting sources.
3. Keep exact source identities, primary-source locators, relevance, and known
   limitations beside each selected item. A review can map the field but cannot
   replace primary support for a thesis argument.
4. Hand the selected source packet to `academic-writing` for argument
   construction. Send disputed validity or overclaiming concerns to
   `scientific-review`; do not resolve them here.

## Completion

The packet states the question, screened scope, selected source identities,
comparison dimensions, gaps, and the next owner without duplicating the active
literature or bibliography records.
