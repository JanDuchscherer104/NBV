# Reviewed Semantic Memory Boundary

Use semantic recall only for prior decisions, failed approaches, unknown
ownership, or cross-surface context. It is navigation evidence, never current
repository authority.

## Eligibility And Safety

- Use only a prompt-visible, reviewed, read-only, fail-closed retrieval surface.
  If it is absent, unavailable, or unverified, continue with deterministic
  repository sources.
- Exclude code, tests, symbols, and active configuration. Use exact source,
  `rg`, Graphify when eligible, or the code index for those owners.
- Record the retrieved source and authored date. An ingestion date is not an
  authorship or supersession date.

## Reviewed Drawers

- `aria-thesis`: related current thesis context; verify the active Typst owner.
- `aria-literature-reviews`, then matching `aria-papers`: review orientation
  followed by the primary paper for consequential external claims.
- `aria-project-docs`: reviewed project-document context.
- `aria-debriefs`: prior diagnoses, measurements, and failed approaches.
- `aria-codex-history`: only for an explicit raw-history request.

After retrieval, open the exact current source. Retrieval rank, age, chronology,
or semantic similarity never establishes current truth or supersession.
