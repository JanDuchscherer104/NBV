# Reference Index

This directory is intentionally small. It indexes cross-task preferences,
artifact policy, and operator aids; it does not duplicate package contracts,
source behavior, or generated documentation.

- `human_owner_intent.md`: reviewed human preferences that apply across tasks.
- `omx_artifact_policy.md`: repository-specific retention rules for tracked OMX
  plans and specifications.
- `operator_quick_reference.md`: practical environment, worktree, frame, and
  EFM-view recovery aids that are not canonical project state.
